A collection of SQL queries created for learning and revising SQL concepts for **Data Analytics and technical interviews**.

This repository is for:

- Revising SQL concepts

- Keeping a personal reference of SQL syntax and examples

# 🛠️ SQL Environment

The queries are primarily written using **MySQL syntax**.

The practice file contains examples using databases such as:

- `practice1`
- `practice_store`
- `ecommercedb`
- `hr`
- `modelcarsdb`

Some queries depend on these databases and their respective tables being available in the MySQL environment.

# 🚀 How to Use

1. Clone or download this repository.
2. Open `Practice_for_interviews.sql` in **MySQL Workbench** or another MySQL-compatible SQL client.
3. Execute the queries section by section.
4. Read the comments in the SQL file to understand each exercise.
5. Modify the queries and experiment with different conditions and datasets.
6. Use the file as a revision resource while preparing for SQL interviews.
